# Wiki mirror

This folder is a mirror of the [GitHub Wiki](https://github.com/dpipstudio/botwave/wiki) for this repo, synced automatically so the docs are readable directly from the repository (useful for anyone, or any tool, that only reads the repo and doesn't browse the wiki separately).

Start at [`Home.md`](Home.md). It is the wiki's entrypoint.

**Note on links:** pages in this folder still contain their original GitHub wiki cross-links, so links between pages point to the live GitHub wiki, not to the local files in this folder. If you're browsing this mirror offline or want to stay within the repo, you'll need to match the linked page name to its corresponding `.md` file in this directory.

This folder is auto-generated and overwritten on every sync. Don't edit these files directly, edit the [wiki](https://github.com/dpipstudio/botwave/wiki) instead. The wiki can be edited locally by cloning `https://github.com/dpipstudio/botwave.wiki.git`.
